# Sole & Stitch — Admin Frontend (React)

React admin panel: login + dashboard with Add Category, Add Item, Add Quantity, View Order.
Talks to the .NET backend at http://localhost:5000/api (see ../ECommerceApp/README.md).

## Run it (in VS Code terminal)

```
npm install
npm run dev
```

Then open the URL it prints (usually http://localhost:5173).

Demo login: admin@shoeshop.com / Admin@123 (created by the backend's seed data).

If your backend runs on a different port, change API_BASE_URL in src/api/api.js.
